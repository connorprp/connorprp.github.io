GBN Platform

At Golf Business Network I own the platform end to end: a suite of custom WordPress plugins (job board, events, member directory, mobile API), a hosted platform of nine MCP servers that let the team work through Claude, an Expo / React Native app for iOS and Android, and a monitoring service that watches all of it. The code is private; the case studies on my GitHub profile walk through the design and the numbers.

Earshot

An ambient conversation dashboard. A native capture agent listens to mic and system audio, runs Whisper locally, and streams transcript lines to a Node hub, where the Claude Agent SDK distills the conversation into live concept bubbles with suggested actions (calendar, email, spreadsheet, notes). Multi-tenant with Google sign-in, Windows and Mac installers, self-updating agents. Source

Bird Targets

Answers "which life birds are being seen near me right now, and where?" Pulls recent observations from the eBird API, subtracts your life list, and maps the nearest sightings with checklist links and directions. Vue 3 front end, Express back end, runs in Docker on my own server. Source
