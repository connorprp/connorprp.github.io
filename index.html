Work at Golf Business Network

GBN is a membership network for private golf clubs. When I started, the platform was WordPress plus about a hundred third-party plugins, a Tableau subscription, a paid job board, and a CRM nobody fully trusted. Over 2026 I replaced the parts that mattered with things I own. The code is private; the write-ups below are public, with the architecture and the real numbers.

  • The job board

    Replaced WP Job Manager and five add-ons with an in-house careers hub, migrated the history without emailing anyone, and parsed résumés with Claude.

    • 9 tables
    • 226-assertion self-test
    • zero broken inbound links at go-live

  • An MCP platform for the whole company

    Nine MCP servers in one Python service so the team works through Claude against the CMS, CRM, database, events and wiki.

    • 112 tools
    • OAuth bridge to WordPress
    • per-tool permissions, every call logged

  • A native app with no second backend

    Expo app plus its WordPress API, contract-first, with types generated from the spec.

    • 49-path OpenAPI contract
    • 92-check API suite
    • iOS and Android from one codebase

  • Monitoring that doesn't trust the thing it watches

    Snapshot-and-diff change ledger, 109 checks, signed runbooks, then a fork for my own home network.

    • 21 collectors
    • alert path never touches WordPress

  • Two outages and a 20x fix

    Email-day traffic was loading 109 plugins per webhook. Scoped it to 21 and the server recovered mid-outage.

    • 388 MB to 14 MB per request
    • 5.4 s to 0.26 s flow editor

Stack across all of it: PHP 7.4 to 8.2 and WordPress internals, Python (FastMCP, FastAPI, Starlette), TypeScript and React Native, Vue 3, MySQL and SQLite, Docker on Coolify, Render, Cloudflare, and the Claude Agent SDK and Messages API.

Projects with public code

  • Earshot

    An ambient conversation dashboard. A native agent captures mic and system audio, runs Whisper locally on the GPU, and streams transcript lines to a Node hub. The Claude Agent SDK distills the conversation into live concept bubbles with hedged actions attached (calendar, email, spreadsheet, note). Multi-tenant, Google sign-in, Windows and Mac installers, agents that self-update from a tarball hash instead of a version number. The echo-suppression layer took longer than the rest of the capture pipeline combined.

    • Source for Earshot
    • earshot.rustycloud.dev

  • Bird Targets

    Answers "which life birds are being seen near me right now, and where?" Pulls recent observations from the eBird API, subtracts my life list, and maps the nearest sightings with checklist links and directions. Vue 3 and Express in Docker on my own server. Small on purpose. It does one thing I actually use.

    • Source for Bird Targets
    • bird-targets.rustycloud.dev
