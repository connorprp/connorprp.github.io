RankedEuchre

Free, browser-first ranked online euchre: no ads, no sign-up required to play. A monorepo with a pure rules engine (unit tested), an Express 5 + Socket.IO backend for real-time multiplayer, and a Vue 3 frontend. Live at rankedeuchre.com.

Flyweight Systems

Full-stack MEVN app (MongoDB, Express, Vue 3, Node) deployed as a single service: Express serves the built Vue SPA and the JWT-authenticated API. Self-hosted on my own server behind Coolify. Source

Tournament Payouts

A Chrome extension that calculates cash payouts for golf tournaments, allocating each place's percentage to the nearest even dollar and showing the remainder. Source
